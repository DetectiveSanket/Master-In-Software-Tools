⁡⁢⁣⁣🔹 𝗣𝗿𝗼𝗳𝗲𝘀𝘀𝗶𝗼𝗻𝗮𝗹 𝗗𝗲𝗳𝗶𝗻𝗶𝘁𝗶𝗼𝗻
        - Connecting local Git to GitHub means linking a local Git repository with a 
           remote repository so that code changes can be shared, synchronized, and collaborated on.

    👉 ⁡⁣⁢⁣In simple words:⁡
        You are connecting your laptop repo to GitHub repo.

[-----------------------------------------------------------------------------]

⁡⁢⁣⁣🧠 𝗖𝗼𝗿𝗲 𝗜𝗱𝗲𝗮 𝗬𝗼𝘂 𝗠𝘂𝘀𝘁 𝗨𝗻𝗱𝗲𝗿𝘀𝘁𝗮𝗻𝗱 𝗙𝗜𝗥𝗦𝗧
⁡
    - Local repo  → exists on your computer
    - Remote repo → exists on GitHub
    - They are separate until you connect them
    
    !⁡⁣⁣⁢ Git does NOT auto-connect anything.⁡

[-----------------------------------------------------------------------------]

⁡⁢⁣⁣🧩 𝗦𝘁𝗲𝗽 𝟭: 𝗖𝗿𝗲𝗮𝘁𝗲 𝗮 𝗥𝗲𝗽𝗼𝘀𝗶𝘁𝗼𝗿𝘆 𝗼𝗻 𝗚𝗶𝘁𝗛𝘂𝗯
⁡
   ⁡⁣⁢⁣ 𝗪𝗵𝗮𝘁 𝘆𝗼𝘂 𝗱𝗼 𝗼𝗻 𝗚𝗶𝘁𝗛𝘂𝗯 (𝗨𝗜 𝘀𝘁𝗲𝗽):⁡
    
    1. Go to GitHub.
    2. Click "New Repository".
    3. Enter:
        - Repository name
        - Public / Private
    4. ❌ Do NOT add README (for now)
    5. Click "Create Repository".

    Now GitHub gives you a remote URL, like:
    👉⁡⁣⁢⁢ https://github.com/username/my-project.git⁡

    📌 ⁡⁣⁣⁢This is the address of your remote repo.⁡

[-----------------------------------------------------------------------------]

⁡⁢⁣⁣🧠 𝗦𝘁𝗲𝗽 𝟮: 𝗪𝗵𝗮𝘁 𝗶𝘀 𝗼𝗿𝗶𝗴𝗶𝗻?
⁡
       - `⁡⁣⁣⁢origin⁡` is the default name given to a remote repository URL.

       - origin = nickname for GitHub repo
        (Easier than typing full URL every time)

[-----------------------------------------------------------------------------]

🛠️ ⁡⁢⁣⁣𝗦𝘁𝗲𝗽 𝟯: 𝗖𝗼𝗻𝗻𝗲𝗰𝘁 𝗟𝗼𝗰𝗮𝗹 𝗥𝗲𝗽𝗼 𝘁𝗼 𝗚𝗶𝘁𝗛𝘂𝗯⁡

    Inside your local project folder:

    👉 ⁡⁣⁢⁣Command⁡:
        ⁡⁢⁢⁢git remote add origin https://github.com/username/my-project.git⁡

    📌 ⁡⁣⁢⁣Meaning⁡:
        - `remote add` → add a remote
        - `origin`     → name
        - `URL`        → GitHub repo address

    🔍 ⁡⁣⁢⁣Verify Connection:⁡
       ⁡⁢⁢⁢ git remote -v⁡

   ⁡⁣⁢⁣ Expected Output:⁡
        origin  https://github.com/username/my-project.git (fetch)
        origin  https://github.com/username/my-project.git (push)

    ✅ Connected successfully.

[-----------------------------------------------------------------------------]

🚀⁡⁢⁣⁣ 𝗦𝘁𝗲𝗽 𝟰: 𝗣𝘂𝘀𝗵 𝗖𝗼𝗱𝗲 𝘁𝗼 𝗚𝗶𝘁𝗛𝘂𝗯 (𝗴𝗶𝘁 𝗽𝘂𝘀𝗵)⁡

    🔹Definition:
        `⁡⁣⁣⁢git push⁡` uploads local commits to a remote repository.


        - Push = send code to GitHub

    👉 ⁡⁣⁢⁣𝗖𝗼𝗺𝗺𝗮𝗻𝗱⁡:
        ⁡⁢⁢⁢git push -u origin main⁡
        git = Git command
        push = upload commits
        -u = set upstream (link local branch to remote)
        origin = remote name
        main = branch name

    # ⁡⁣⁢⁣𝘂𝗽𝘀𝘁𝗿𝗲𝗮𝗺 (-𝘂) 𝗲𝘅𝗽𝗹𝗮𝗶𝗻𝗲𝗱 𝗶𝗻 𝗻𝗲𝘅𝘁 𝗰𝗵𝗮𝗽𝘁𝗲𝗿⁡
       - -u sets the default remote branch for future pushes and pulls.


    📌 `⁡⁣⁣⁢-u⁡` sets default upstream (do once). 
       After this, `git push` is enough.

      ⁡⁢⁣⁢ ⁡⁢⁢⁢𝗕𝘂𝘁 𝗶𝗳 𝘆𝗼𝘂 𝘀𝘁𝗶𝗹𝗹 𝘄𝗮𝗻𝘁 𝘁𝗼 𝗰𝗿𝗲𝗮𝘁𝗲 𝗮 𝗻𝗲𝘄 𝗯𝗿𝗮𝗻𝗰𝗵 𝗮𝗻𝗱 𝗽𝘂𝘀𝗵:⁡⁡
       - git switch -c feature-login
       - git push -u origin feature-login
        > This creates and pushes new branch.
        > if you just do `git push` without `-u`, Git will ask where to push.

        Know this: If you forget `-u` on first push, you can fix it later with:
        - git push -u origin main

        if you want to push to a main branch that already exists, you can just do:
        - git push origin main

[-----------------------------------------------------------------------------]

⬇️ ⁡⁢⁣⁣𝗦𝘁𝗲𝗽 𝟱: 𝗣𝘂𝗹𝗹 𝗖𝗼𝗱𝗲 𝗳𝗿𝗼𝗺 𝗚𝗶𝘁𝗛𝘂𝗯 (𝗴𝗶𝘁 𝗽𝘂𝗹𝗹)⁡

    🔹 ⁡⁣⁢⁣Professional Definition:⁡
        `git pull` fetches and merges changes from the remote repository(GitHub) 
        into the local repository (Laptop).

    🔹 ⁡⁣⁢⁣Simple Explanation:⁡
        ⁡⁣⁣⁢Pull = get latest code from GitHub⁡

    👉 ⁡⁣⁢⁣Command⁡:
        ⁡⁢⁢⁢git pull⁡

    📌 ⁡⁣⁢⁣Used when:⁡
        - Someone else pushed code.
        - You want latest updates.
        - You are working on multiple machines.
   

[-----------------------------------------------------------------------------]

📥 ⁡⁢⁣⁣𝗦𝘁𝗲𝗽 𝟲: 𝗖𝗹𝗼𝗻𝗲 𝗮 𝗥𝗲𝗽𝗼𝘀𝗶𝘁𝗼𝗿𝘆 (𝗴𝗶𝘁 𝗰𝗹𝗼𝗻𝗲)⁡

    🔹 ⁡⁣⁢⁣Professional Definition:⁡
        ⁡⁣⁣⁢`𝗴𝗶𝘁 𝗰𝗹𝗼𝗻𝗲`⁡ creates a local copy of a remote repository (present on Github).

    🔹 ⁡⁣⁢⁣𝗦𝗶𝗺𝗽𝗹𝗲 𝗘𝘅𝗽𝗹𝗮𝗻𝗮𝘁𝗶𝗼𝗻:⁡
        Clone = download project first time
    
    👉 ⁡⁣⁢⁣Command⁡:
        ⁡⁢⁢⁢git clone https://github.com/username/project.git⁡

    📌 ⁡⁣⁢⁣Automatically⁡:
        - Creates folder.
        - Initializes Git.
        - Connects remote.

[-----------------------------------------------------------------------------]
