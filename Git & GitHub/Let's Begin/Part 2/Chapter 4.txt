Chapter 4: Creating & Understanding a Repository
------------------------------------------------
   - git init
   - .git folder (hidden brain of Git)
   - First repository walkthrough

[--------------------------------------------------------------------------------------------]   

- A Git repository is a directory that contains a project’s files along with the complete history of changes tracked by Git.

    👉 In simple words:
        - A repository is a normal folder that Git is actively watching and remembering.

    🧠 Key Question: When Does Git Start Working?

    👉 Git does NOTHING until you initialize a repository.

        >< That means:

            - Files exist ❌
            - Git tracking ❌
            - History ❌

        > Git starts only after git init    


[--------------------------------------------------------------------------------------------]

🛠️ git init (Birth of Git in a Folder)
        - git init initializes a new Git repository by creating a .git directory that stores Git’s metadata and object database.

    >< Simple Explanation:
        - git init tells Git:
            - “Start tracking this folder”

[--------------------------------------------------------------------------------------------]

🧪 Practical (DO THIS STEP-BY-STEP)

    1️⃣ Create a new folder
        - my-git-project

    2️⃣ Open terminal inside it

    3️⃣ Run:
        - git init

    Output:
        - Initialized empty Git repository

    🎉 Your folder is now a Git repository

    🧠 What Actually Happened?
        - A hidden folder got created:
            my-git-project/
            └─ .git/

        ⚠️ This .git folder is everything

[--------------------------------------------------------------------------------------------]

🧠 The .git Folder (Hidden Brain of Git)
     - The .git directory contains all metadata, objects, references, and configuration required for Git to manage version control.

    <> Simple Explanation:
        - .git = Git’s brain
        - Stores:
            - Commit history
            - Branches
            - HEAD pointer
            - Config
            - Logs

📌 If .git is deleted → Git history is gone

📂 Inside .git (High-Level View)

        .git/
        ├─ objects/     ← actual data (snapshots)
        ├─ refs/        ← branches & tags
        ├─ HEAD         ← current position
        ├─ config       ← repo settings


❌ You normally don’t touch this manually

[--------------------------------------------------------------------------------------------]

🧪 First Repository Walkthrough

    Create a file:

        index.js

    Add code:

        console.log("Hello Git");


    Now run:

        git status


    Output:

        Untracked files:
        index.js


    📌 This means:
        - Git sees the file
        - But is not tracking it yet

    This leads us directly to the next chapter 👇

[--------------------------------------------------------------------------------------------]

📝 Chapter 4 – Notes (Revision Ready)

        - Git works only inside a repository
        - git init starts Git tracking
        - .git folder stores all history
        - Deleting .git removes Git
        - Files are NOT tracked automatically
