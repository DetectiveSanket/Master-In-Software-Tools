❓ ⁡⁣⁢⁣𝗣𝗿𝗼𝗯𝗹𝗲𝗺 𝗕𝗲𝗳𝗼𝗿𝗲 𝗚𝗶𝘁 (𝗥𝗲𝗮𝗹-𝗟𝗶𝗳𝗲 𝗦𝘁𝗼𝗿𝘆)⁡

    Imagine this situation 👇
    -> You are working on a project:
            project/
             ├─ final_code.js

      <> ⁡⁣⁣⁢You make some changes… but you’re not sure if it’s correct.⁡
      
    - ⁡⁢⁢⁢So what do you do? ⁡    
        -> final_code_v1.js
        -> final_code_v2.js
        -> final_code_final.js
        -> final_code_final_final.js
        -> final_code_final_latest.js 😵

    # ⁡⁢⁢⁢Now imagine:⁡
        - You broke something
        - You don’t know which file was correct
        - You want to go back to yesterday’s working code
        👉 This was life before Git    

[--------------------------------------------------------------------]

🧠 ⁡⁢⁣⁣𝗧𝗵𝗲 𝗖𝗼𝗿𝗲 𝗣𝗿𝗼𝗯𝗹𝗲𝗺 𝗚𝗶𝘁 𝗦𝗼𝗹𝘃𝗲𝘀⁡

    ⁡⁣⁢⁣Git solves 3 big problems:⁡
        🔙 Go back to old versions of code
        🧪 Try new changes without breaking main code
        👥 Allow many people to work on same project safely   

    🧰⁡⁣⁢⁣ So… What is Git? (Simple Definition)⁡
        - ⁡⁣⁣⁢Git is a version control system.⁡

    <> ⁡⁣⁢⁣Still sounds complex? Let’s simplify⁡ 👇
        👉 Git is like a time machine for your code
            - It remembers every important change
            - You can go back to any previous state
            - You can see who changed what and when    

[--------------------------------------------------------------------]

🗂️⁡⁢⁣⁣ 𝗪𝗵𝗮𝘁 𝗘𝘅𝗮𝗰𝘁𝗹𝘆 𝗗𝗼𝗲𝘀 𝗚𝗶𝘁 𝗧𝗿𝗮𝗰𝗸?⁡

    ⁡⁣⁢⁣Git tracks:⁡
        - Files
        - Code changes (line by line)
        - Who made the change
        - When the change was made
        - Why the change was made (commit message)

    # ⁡⁢⁢⁢So, Git is like a time machine for your code⁡

[--------------------------------------------------------------------]   

🧱 ⁡⁢⁣⁣𝗜𝗺𝗽𝗼𝗿𝘁𝗮𝗻𝘁 𝗪𝗼𝗿𝗱: 𝗥𝗲𝗽𝗼𝘀𝗶𝘁𝗼𝗿𝘆 (𝗥𝗲𝗽𝗼)⁡
   ≽ ⁡⁣⁣⁢A repository is a folder that Git is watching.⁡

    ex:-
        my-project/ ← Repo
        ├─ index.html
        ├─ style.css
        ├─ app.js
        └─ .git/   ← Git brain (hidden)

    - .git folder = Git’s memory
    - Without .git, Git doesn’t exist

📝 ⁡⁢⁣⁣𝗖𝗵𝗮𝗽𝘁𝗲𝗿 𝟭 – 𝗡𝗼𝘁𝗲𝘀 (𝗥𝗲𝘃𝗶𝘀𝗶𝗼𝗻 𝗥𝗲𝗮𝗱𝘆)⁡

    - Git = Version control system
        - Keeps history of code changes
        - Solves backup, experimentation & collaboration
    - Repo = Folder tracked by Git
    - .git = Git’s brain
    - Git works locally
    - GitHub is Platform to stores code online
