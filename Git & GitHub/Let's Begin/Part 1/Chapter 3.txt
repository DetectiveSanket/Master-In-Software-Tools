🔹⁡⁣⁢⁣Professional Definition (Important)⁡
    - Git installation and configuration is the process of setting up Git on a system and defining user identity so that every commit can be correctly attributed to its author.

⁡⁣⁢⁣In simple word⁡s 👇
    - Git must know who you are, otherwise it cannot properly record history.

[--------------------------------------------------------------------------------------------]

🧠 ⁡⁢⁣⁣𝗖𝗼𝗿𝗲 𝗜𝗱𝗲𝗮 𝗬𝗼𝘂 𝗠𝘂𝘀𝘁 𝗥𝗲𝗺𝗲𝗺𝗯𝗲𝗿⁡

    👉 ⁡⁣⁢⁣In company projects, this is non-negotiable.⁡
        <> Whenever you make a commit, Git stores:
            1. Who made the change
            2. Email of the author
            3. Time of commit

    ⁡⁣⁣⁢Managers, reviewers, and CI systems rely on this data.⁡

[--------------------------------------------------------------------------------------------]

🛠️ ⁡⁢⁣⁣𝗦𝘁𝗲𝗽 𝟭: 𝗖𝗵𝗲𝗰𝗸 𝗶𝗳 𝗚𝗶𝘁 𝗜𝘀 𝗜𝗻𝘀𝘁𝗮𝗹𝗹𝗲𝗱⁡

    - Open terminal / command prompt and type:
        
        ⁡⁢⁢⁢git --version⁡

    Output example:
       ⁡⁢⁢⁢ git version 2.43.0⁡

    ✅ If you see a version → Git is installed
    ❌ If not → install Git

[--------------------------------------------------------------------------------------------]

🛠️ ⁡⁣⁣⁢𝗦𝘁𝗲𝗽 𝟮: 𝗜𝗻𝘀𝘁𝗮𝗹𝗹𝗶𝗻𝗴 𝗚𝗶𝘁 (𝗤𝘂𝗶𝗰𝗸 𝗢𝘃𝗲𝗿𝘃𝗶𝗲𝘄)⁡

    ⁡⁣⁢⁣Windows⁡:
        - Download from official Git website
        - Install with default settings (safe)

    ⁡⁣⁢⁣macOS⁡:
        - brew install git

    ⁡⁣⁢⁣Linux⁡:
        - sudo apt install git

    📌 Since you already use VS Code source control, Git is already installed in your system.

[--------------------------------------------------------------------------------------------]

🧠 ⁡⁢⁣⁣𝗦𝘁𝗲𝗽 𝟯: 𝗚𝗶𝘁 𝗖𝗼𝗻𝗳𝗶𝗴𝘂𝗿𝗮𝘁𝗶𝗼𝗻 (𝗠𝗢𝗦𝗧 𝗜𝗠𝗣𝗢𝗥𝗧𝗔𝗡𝗧 𝗣𝗔𝗥𝗧)⁡

    🔹⁡⁣⁢⁣Professional Meaning:⁡
        - Git configuration defines identity and behavior settings used during repository operations.

    1️⃣ ⁡⁣⁢⁣Set Your Name⁡
        ⁡⁢⁢⁢git config --global user.name "Your Name"⁡

        Example:
        ⁡⁢⁢⁢git config --global user.name "Sanket Navale⁡"

    2️⃣ ⁡⁣⁢⁣Set Your Email⁡
        ⁡⁢⁢⁢git config --global user.email "your@email.com"⁡

        📌 Use same email as GitHub account
        (⁡⁣⁣⁢Important for commit linking on GitHub⁡)

[--------------------------------------------------------------------------------------------]

⁡⁢⁣⁣🌍 𝗪𝗵𝗮𝘁 𝗗𝗼𝗲𝘀 --𝗴𝗹𝗼𝗯𝗮𝗹 𝗠𝗲𝗮𝗻?
⁡
    ---------------------------------------------
    | ⁡⁣⁢⁣Type    | Meaning⁡                         |
    | ------- | ------------------------------- |
    | --global| Applies to all projects         |
    | --local | Applies to current project only |
    ---------------------------------------------

    📌⁡⁣⁢⁣ Industry rule:⁡
        Use --global for personal identity

[--------------------------------------------------------------------------------------------]

🔍 ⁡⁢⁣⁣𝗩𝗲𝗿𝗶𝗳𝘆 𝗖𝗼𝗻𝗳𝗶𝗴𝘂𝗿𝗮𝘁𝗶𝗼𝗻⁡

    Command:
        ⁡⁢⁢⁢git config --list⁡

    You will see:
        ⁡⁢⁢⁢user.name=Your Name
        user.email=your@email.com⁡

    🧭 Where Does Git Store This?
        - ⁡⁢⁢⁢Windows: .gitconfig file
        - macOS/Linux: ~/.gitconfig⁡

    👉 ⁡⁣⁣⁢Git automatically reads this file⁡

[--------------------------------------------------------------------------------------------]

⚠️ ⁡⁢⁣⁣𝗖𝗼𝗺𝗺𝗼𝗻 𝗕𝗲𝗴𝗶𝗻𝗻𝗲𝗿 𝗠𝗶𝘀𝘁𝗮𝗸𝗲𝘀⁡

    ❌ Not setting name/email
    ❌ Using different email than GitHub
    ❌ Changing config inside repo without understanding
    ❌ Copy-pasting random commands

🧪 ⁡⁢⁣⁣𝗠𝗶𝗻𝗶 𝗣𝗿𝗮𝗰𝘁𝗶𝗰𝗮𝗹 (𝗗𝗼 𝗧𝗵𝗶𝘀 𝗢𝗻𝗰𝗲)

        git config --global user.name "Your Name"

📝 ⁡⁢⁣⁣𝗖𝗵𝗮𝗽𝘁𝗲𝗿 𝟯 – 𝗡𝗼𝘁𝗲𝘀 (𝗥𝗲𝘃𝗶𝘀𝗶𝗼𝗻)⁡

    - Configuration defines commit author
    - user.name and user.email are mandatory
    - --global applies to all repos
    - Git reads config automatically
